# Calm Router

**A 30-second check-in that routes you to the right coping skill.**

Tell it how you're doing, and it matches your current mood to a skill from the Coping Skills Menu — so you don't have to think in the middle of a hard moment.

Live app: https://calm-router.vercel.app

## What it does

- **30-second check-in** — pick your state, get matched, go
- **Coping Skills Menu** — every skill in one place, sorted by what it's for
- **Low-effort by design** — decisions are the hard part in a hard moment; this makes fewer of them for you

## Built with

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

## Run it locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Why

When you're spiralling, "which skill should I use?" is the question that stops everything. Calm Router answers it in half a minute.
